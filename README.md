## <img src="assets/fenix-mascot.png" alt="Project Fénix mascot" height="38" align="center" /> Project Fénix: Systematic Repository Modernization

> **Project Fénix** is an engineering initiative dedicated to refactoring and upgrading foundational scripts and legacy prototypes into production-grade systems. Each repository is rebuilt with modular architectures, modern web stacks (`FastAPI`, `Next.js 15`, `Tailwind CSS v4`, `uv`), automated testing, and high-performance data pipelines.

| Repository / System | Architecture & Engineering Scope | Core Tech Stack | Status |
| :--- | :--- | :--- | :---: |
| **[Yahoo-Finance-Data-Visualization](https://github.com/Dmgar/Yahoo-Finance-Data-Visualization-Analysis)** | **Forex & Market Volatility Platform:** High-performance Monorepo featuring a `FastAPI` backend managed by `uv`, `Next.js 15` (`Tailwind v4` + `Recharts`), technical risk indicators (ATR, Bollinger Bands, MACD, Drawdowns), and an active roadmap for live WebSockets. | `Next.js 15` · `FastAPI` · `uv` · `Tailwind v4` · `Recharts` | <img src="assets/status-reborn.png" alt="Status: Reborn" width="150" /> |
| **[Experimentos-Fisicos (PhysLab)](https://github.com/Dmgar/Experimentos-fisicos)** | **Computational Physics & Optical Perception Lab:** Scientific Monorepo with `React 19` + `Vite` + `TypeScript` and `FastAPI`. Includes 60 FPS Canvas simulations (chaotic double pendulum, quadratic drag, harmonic resonance) and a real-time `OpenCV` computer vision tracker (MOG2, PCA harmonic eigenvector projection on real lab video with $R^2 > 0.998$). | `React 19` · `FastAPI` · `OpenCV` · `SciPy` · `TypeScript` · `uv` | <img src="assets/status-reborn.png" alt="Status: Reborn" width="150" /> |
| **[Colombia-Pobreza-Multidimensional](https://github.com/Dmgar/Colombia-pobreza-multidimensional)** | **Socioeconomic Intelligence & LatAm Benchmarking:** Comparative platform contrasting Colombia's IPM against 9 Latin American peers and OECD/ECLAC standards. Includes 5-pillar radars, Poverty vs. Gini quadrants, macroeconomic welfare analysis, policy simulator, and a pure-Python GeoJSON engine (552 KB vector map loading in 15 ms). | `Python` · `Dash` · `Plotly` · `PyShp` · `Shapely` | <img src="assets/status-reborn.png" alt="Status: Reborn" width="150" /> |
| **[Corporate-BI-Dashboard](https://github.com/Dmgar/corporate-bi-dashboard)** | **Commercial Intelligence Engine:** Rebuilt from exploratory notebooks into an interactive executive dashboard. Powered by modular `.sql` queries executed via `DuckDB`/`SQLite`, synthetic transaction generation (~100k records), automated business alerts, and product-level drill-down. | `SQL` · `DuckDB` · `Python` · `Streamlit` · `Plotly` | <img src="assets/status-reborn.png" alt="Status: Reborn" width="150" /> |
| **[Exoplanet-Outlier-Detector](https://github.com/Dmgar/exoplanet-outlier-detector)** | **AstroData Outlier Pipeline:** Upgrading astrophysical pipelines for Kepler, K2, and TESS light curves with modular statistical algorithms, noise reduction, and transit candidate scoring. | `Python` · `Lightkurve` · `NumPy` · `AstroData` | <img src="assets/status-in-progress.png" alt="Status: In Progress" width="150" /> |
